# Bug Reporting Instructions

## Prompt for Creating a Bug Report from My Description

I'm going to describe a bug (either by typing or speaking).

Please listen to or read my description carefully and then create a professional, detailed bug report using the following format:

### Title
Short and clear summary of the issue.

### Environment
Mention if I say where it happens (e.g., staging, production).

### Steps to Reproduce
Step-by-step process to trigger the issue.

### Actual Result
What is happening now (the problem).

### Expected Result
What should happen instead.

### Notes / Attachments
If I mention screenshots or videos, note them here.

Make sure the wording is simple, easy to read, and professional — suitable for Jira or QA documentation.
